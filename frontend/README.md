# Panaceya - Frontend

A beautiful, modern landing page for the Panaceya surgical training platform.

## Design Theme
- **Primary Color**: #00A1F1 (Medical Blue)
- **Style**: Clean Medical + Calm Tech Futurism
- **Effects**: Glassmorphism, smooth animations, gradient overlays

## Tech Stack
- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Framer Motion (animations)
- Lucide React (icons)

## Getting Started

### Install Dependencies
```bash
npm install
```

### Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the landing page.

### Build for Production
```bash
npm run build
npm start
```
